## Русский

В этом выпуске проще планировать месяц, находить настройки и управлять таймером
с рабочего стола. На устройстве приложение теперь называется **OTM**, а файл
установки — **`OTM.apk`**. Это то же приложение, с прежними данными и подписью.

### Что нового

- **План и баланс месяца.** Задайте часы и минуты отдельно для каждого месяца,
  сравните план с подтверждённым временем и переходите между месяцами.
  Оценка по будням применяется только по вашему выбору и не учитывает праздники.
- **Мастер настройки Android.** Необязательные шаги помогают проверить уведомления
  и фоновые ограничения. Можно пропустить; разрешения не включаются сами.
  При обновлении мастер не навязывается, его можно открыть из настроек.
- **Поиск настроек.** Компактные разделы находятся по названиям и ключевым словам.
  Уведомления, виджет, плитка и ограничения фона собраны в «Android и устройство».
- **Новый виджет.** Адаптивные компактная, широкая и высокая карточки, светлая
  и тёмная системные темы, крупный таймер и доступные кнопки управления.
- **Дневной прогресс в уведомлении.** Учитывает все проекты и текущий рабочий
  отрезок. Android 16 показывает сегментированный прогресс; Android 12–15 — обычную
  полосу. Хронометр по-прежнему относится к текущей сессии.
- **Удобнее ввод.** Формы прокручиваются целиком, черновики сохраняются при
  пересоздании экрана, клавиатура временно скрывает нижнюю навигацию.
  Улучшены узкие окна и крупный шрифт. Отказ в уведомлениях не считается сбоем таймера.

### Экспериментальная интеграция

«Live Updates и HyperIsland» остаётся **выключенной по умолчанию**. Android 16
решает, выделять ли уведомление. Для HyperOS 3 подготовлен локальный шаблон,
но регистрация Xiaomi, app ID, привязка сертификатов и допуск сценария ещё не
получены. Работа острова на физическом устройстве **не подтверждена**.
Обычный таймер и уведомление не требуют этой опции.

### Обновление и данные

- Установите **`OTM.apk`**, версия 1.2.0, `versionCode = 4`, поверх 1.1.0.
  Production-ключ и идентификатор `dev.opentimemanager.app` сохранены.
- Сначала сохраните и проверьте зашифрованную копию. При ошибке подписи
  не удаляйте приложение и не очищайте данные ради установки.
- Схема Room остаётся v4; форматы копий не менялись. Месячные планы, язык,
  проект по умолчанию и локальные настройки интеграций не входят в копии.
- `.otmplain` и CSV открыты для получателя. Для обычного хранения используйте
  `.otmbackup`. Успешную замену данных при восстановлении нельзя отменить.

Результаты тестов, проверки обновления и ограничения указаны в `VERIFICATION.md`
рядом с APK. Там же доступны контрольные суммы, сведения о production-сертификате,
commit и архив соответствующих исходников. Галерея сохраняет честное происхождение
снимков dev-сборок перед выпуском. Проверки на эмуляторах не заменяют испытаний
всех прошивок; расход батареи и продвижение OEM-уведомлений не измерялись.

## English

This release makes monthly planning, settings, and home-screen tracking easier.
The app is now called **OTM** on your device and the installer is **`OTM.apk`**.
It is the same app, with the same data and production signing identity.

### What's new

- **Monthly plans and balances.** Set hours and minutes for each calendar month,
  compare with confirmed work, and navigate between months. The optional weekday
  estimate applies only when selected and does not account for holidays.
- **Optional Android setup.** Check notifications and background restrictions,
  or skip. Permissions never enable themselves. Existing installations are not
  forced through setup; reopen it from Settings when needed.
- **Settings search.** Find focused sections by setting names or keywords.
  Android and device groups notifications, the widget, tile, and background limits.
- **Redesigned widget.** Responsive compact, wide, and tall cards follow the
  system light/dark theme, with a prominent timer and accessible controls.
- **Daily notification progress.** Includes all projects and the running interval.
  Android 16 uses segmented progress; Android 12–15 use a standard bar.
  The chronometer still measures the current session.
- **Better forms.** Whole-dialog scrolling, restored drafts, more space while the
  keyboard is open, and improvements for narrow windows and large fonts.
  Denied optional notifications no longer appear as timer failures.

### Experimental integration

Live Updates and HyperIsland remains **off by default**. Android 16 decides
whether to promote a notification. A local HyperOS 3 template is prepared, but
Xiaomi registration, an app ID, signing-certificate registration, and scenario
approval have not been obtained. A working island on a physical device is
**unconfirmed**. Normal tracking and notifications do not need this option.

### Update and data

Install **`OTM.apk`**, version 1.2.0, version code 4, over 1.1.0. The production
key and `dev.opentimemanager.app` ID are unchanged. Save and check an encrypted
backup first. Do not uninstall or clear data to bypass a signature mismatch.

Room remains at schema v4; backup formats are unchanged. Monthly plans, language,
the default project, and local integration preferences stay outside backups.
`.otmplain` and CSV are readable by anyone receiving them. Prefer `.otmbackup`
for storage; a successful Replace cannot be undone.

See `VERIFICATION.md` beside the APK for actual tests, upgrade results, and limits.
The release also includes checksums, public certificate details, source commit,
and matching source archive. The gallery retains provenance of pre-release dev
captures. Emulator tests are not certification of every firmware; battery impact
and OEM notification promotion have not been measured.
