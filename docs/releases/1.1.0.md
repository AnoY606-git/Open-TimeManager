# Open TimeManager 1.1.0

## Русский

Этот выпуск упрощает повседневную работу: настройки стали компактнее, появилась
справка, а привычный проект можно выбрать один раз.

### Что нового

- **Настройки по задачам.** Отдельные страницы для оформления, учёта, копий,
  справки и сведений о приложении.
- **Помощь без интернета.** Десять тем с поиском на русском и английском.
- **Проект по умолчанию.** Предлагается для новой сессии и помогает запускать
  работу из виджета или плитки. Текущий таймер не переключается.
- **Копия без пароля.** Новый `.otmplain` доступен отдельной кнопкой с
  предупреждением. Обычная `.otmbackup` по-прежнему зашифрована и совместима
  с прежними копиями.
- **Удобнее системное управление.** Кнопки добавления плитки и виджета,
  переходы в настройки Android и подсказки о фоновых ограничениях.
- **Live Updates на Android 16.** Можно включить для работающего таймера.
  По умолчанию выключены; полная поддержка зависит от обновления 36.1,
  а вид уведомления выбирает система.

Исправлены устаревшие действия в истории после восстановления, работа редактора
при смене часового пояса, загрузка отчётов и восстановление настроек после ошибок.
На паузе уведомление больше не показывает растущее время. Сокращены лишние
системные обновления; расход батареи отдельно не измерялся.

### Перед обновлением

Сохраните и проверьте зашифрованную копию. В 1.1.0 используется тот же ключ
подписи, что и в 1.0.0; обновление с сохранением записей проверено на эмуляторе.
Установочный файл — **`Open-TimeManager-1.1.0.apk`**, `versionCode = 3`.
У тестовой сборки может быть другая подпись. При несовместимости не удаляйте
приложение и не очищайте данные ради установки.

`.otmplain` и CSV доступны любому получателю файла. Открытую копию можно изменить
и пересчитать её контрольную сумму. Для обычного хранения используйте
зашифрованную копию. Перед режимом «Заменить» сохраните текущие данные отдельно:
успешную замену отменить нельзя.

### Проверки и файлы релиза

На странице выпуска рядом с APK есть `SHA256SUMS`, `SIGNING_CERT.txt`,
`SOURCE_COMMIT.txt`, архив соответствующих исходников и `VERIFICATION.md`
с результатами тестов и границами проверки. Проверки выполнены на эмуляторах
Android 12 и 16; совместимость со всеми прошивками и фактическое выделение
Live Updates не заявляются.

## English

This release makes everyday tracking easier: focused settings, searchable help,
and a default project you only need to choose once.

### What's new

- **Focused Settings pages** for appearance, tracking, backups, help, and app information.
- **Offline help** with ten searchable topics in English and Russian.
- **A default project** for new sessions and widget/tile Start, without changing
  an active timer.
- **Optional unprotected backups.** A separate `.otmplain` action explains the
  risk. Encrypted `.otmbackup` stays the default and keeps existing compatibility.
- **Easier system controls:** tile/widget add buttons, Android settings links,
  and background-restriction tips.
- **Opt-in Android 16 Live Updates** for a running timer. Off by default;
  full support needs system update 36.1, and Android decides presentation.

Fixed stale history actions after restore, time-zone editing, report loading,
and settings recovery. Paused notification time now stays fixed. Repeated system
updates were reduced; battery impact was not measured.

### Before updating

Save and check an encrypted backup. Version 1.1.0 keeps 1.0.0's signing key;
an emulator upgrade preserved existing records. Install **`Open-TimeManager-1.1.0.apk`**,
version code 3. Test builds may use a different key. Do not uninstall or clear
data to force an update after a signature mismatch.

Anyone with `.otmplain` or CSV can read it. An unprotected copy can also be edited
and its checksum recalculated. Use encrypted backups for normal storage.
Before Replace, save current data separately: a successful replacement has no Undo.

### Verification and downloads

The release includes checksums, public certificate details, the source commit,
matching source archive, and `VERIFICATION.md`. Testing used Android 12 and 16
emulators; it does not establish compatibility with every device or actual
Live Update promotion.
