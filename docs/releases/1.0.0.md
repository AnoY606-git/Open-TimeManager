# Open TimeManager 1.0.0

17 октября 2026 · Первый стабильный выпуск / First stable release · Android 12+

[Страница выпуска / Release page](https://github.com/AnoY606-git/Open-TimeManager/releases/tag/v1.0.0) ·
[Русский](#русский) · [English](#english)

## Русский

Первый стабильный Open TimeManager: локальный учёт рабочего времени без аккаунта,
рекламы и подключения к интернету.

### Что вошло в выпуск

- Таймер с паузой, продолжением, сменой проекта и заметками.
- Проекты, архивирование, поиск и редактирование истории, ручные записи.
- Отчёты за неделю, месяц или свой период; экспорт CSV.
- Зашифрованные `.otmbackup`, предпросмотр и восстановление через
  «Объединить» или «Заменить».
- Уведомление, виджет и плитка быстрых настроек со скрытием названий проектов.
- Обновлённый интерфейс: светлая и тёмная темы, цвета устройства,
  русский и английский языки, адаптация к размеру окна.

Улучшены отклик системных команд, повторное открытие предпросмотра восстановления
и экспорт CSV. Новый пароль копии требует не менее 12 символов; старые копии
сохраняют совместимость. Неизвестное время после перезагрузки требует проверки,
а не добавляется автоматически.

### Установка и данные

Файл выпуска — **`Open-TimeManager-1.0.0.apk`**. Контрольные суммы, сертификат,
исходники и отчёт `VERIFICATION.md` находятся рядом на странице релиза.
Сейчас рекомендуется [последняя стабильная версия](https://github.com/AnoY606-git/Open-TimeManager/releases/latest).

Перед переходом с preview/debug сохраните и проверьте зашифрованную копию:
подписи могут отличаться. Не удаляйте приложение и не очищайте данные ради
обхода ошибки подписи. Режим «Заменить» нельзя отменить после успешного импорта.

Шифрование защищает копию, не локальную базу. CSV — открытый файл для таблиц,
не средство восстановления. Забытый пароль не восстанавливается.
Автоматические копии Android отключены. Это выпуск GitHub, не Google Play.

## English

The first stable Open TimeManager release: local work-time tracking without
an account, ads, or an internet connection.

### Included in this release

- A timer with pause, resume, project switching, and notes.
- Projects, archiving, searchable history, editing, and manual entries.
- Weekly, monthly, and custom reports with CSV export.
- Encrypted `.otmbackup` files, preview, and Merge or Replace restore.
- Notification, widget, and Quick Settings controls with hidden project labels.
- Refreshed light/dark themes, device colors, English/Russian text, and adaptive layouts.

Improved system-action response, restore preview retries, and CSV export.
New backup passwords require at least 12 Unicode code points; existing copies
remain compatible. Unknown time after a reboot requires review rather than being
added automatically.

### Installation and data

The release file is **`Open-TimeManager-1.0.0.apk`**, with checksums, public
certificate details, source, and `VERIFICATION.md` on the release page.
For everyday use, choose the [latest stable version](https://github.com/AnoY606-git/Open-TimeManager/releases/latest).

Before moving from preview/debug, save and check an encrypted backup: signatures
may differ. Do not uninstall or clear app data to bypass a signature mismatch.
A successful Replace cannot be undone.

Encryption protects backup files, not the local database. CSV is readable
spreadsheet data, not a restorable copy. Forgotten passwords cannot be recovered.
Android automatic backup is disabled. This is a GitHub release, not Google Play.
